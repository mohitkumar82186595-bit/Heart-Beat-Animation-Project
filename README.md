# Heart-Beat-Animation-Project
❤️ **Heart Beat Animation | HTML • CSS • JavaScript**

Just completed a creative **Heart Beat Animation** using **HTML, CSS, and JavaScript**! 💻✨

This project recreates a realistic heartbeat effect with smooth scaling animations, glowing pulse rings, and floating heart particles to deliver an engaging visual experience—all built without any external libraries.

### 🚀 Features

❤️ Realistic Heart Beat Animation
💓 Expanding Pulse Ring Effect
✨ Floating Heart Particles
🌟 Neon Glow & Smooth CSS Animations
📱 Fully Responsive Design
⚡ Built with Pure HTML, CSS & JavaScript

This project helped me strengthen my understanding of **CSS keyframe animations**, **transforms**, **box-shadow effects**, and **JavaScript DOM manipulation** while creating an interactive UI animation.
